# CivicFlow AI

CivicFlow AI is a predictive queue and bottleneck management system for government service centres.

Instead of simply showing the current queue, CivicFlow predicts future congestion, identifies bottlenecks, analyzes possible causes, simulates interventions, and recommends actions.

## Current Features

- Synthetic government service-centre dataset
- Queue prediction using Machine Learning
- Random Forest regression model
- 30-minute queue forecasting
- Model evaluation using MAE and R²

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib
